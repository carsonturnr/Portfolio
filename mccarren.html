McCarren Capital

software engineer · 2025

Software engineer at McCarren Capital, a private-equity and specialty-finance advisory. I built custom CRM automation on Attio and OpenAI that turned cold investor outreach into booked calls.

the ask

Investor outreach was chased by hand. Follow-ups slipped when the inbox got busy, replies waited, and the pipeline only stayed current if someone updated it manually.

role

Software Engineer, remote, April 2025 to January 2026.

what i built

  • Automatic follow-ups, sent a set time after each touchpoint with an investor.
  • Pipeline stages in Attio that contacts moved through on their own: new, contacted, replied, call booked.
  • Timing rules for each stage, so the wait before the next follow-up depended on where the investor stood.
  • Reply sorting into interested, not now and not interested, which decided the next step.
  • Responses generated with OpenAI from the email thread and the investor’s Attio record.
  • A stop on all automation for an investor once they replied or booked a call.

how it works

An investor is added to Attio and starts in the first stage. The outreach sequence goes out through SuperSend, with each follow-up timed from the last touchpoint. When the investor replies, the reply is sorted, and OpenAI generates a response from the thread and their Attio record, which a person checks before it is sent. Each step updates the investor’s stage through Attio’s API, and the sequence ends once a call is booked.

design choices

  • A person stayed in the loop on replies. In finance, every message to an investor carries the firm’s name.
  • Sending windows and daily limits protected the domain’s sending reputation.
  • Attio was the single source of truth: every send, reply and stage change was written back to it.

results

  • Cold investor outreach turned into booked calls.
  • No more missed follow-ups.
  • Investor replies answered faster.
  • More time on calls instead of chasing follow-ups.
  • A pipeline that was always current.

stack

Python. Attio API. SuperSend. OpenAI API.
