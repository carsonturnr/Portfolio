Mosaic

in progress · 2026

An AI creative strategist for Meta ads, built for brands that can’t afford an in-house strategist. It analyzes every ad, ranks what drives results and writes reports where every number is cited and verified.

problem

Brands run many ad creatives but can’t tell which hooks, angles and formats drive results, or which ads are near-copies of each other. Doing that by hand means watching every ad and lining tags up against spend data, which small teams don’t have time for.

what i built

  • A perception pipeline: scene detection that isolates the first three seconds, then one vision-model call per ad for the transcript, on-screen text and schema-checked tags.
  • Rankings that low-spend ads can’t game, using statistical shrinkage (beta-binomial and gamma-Poisson), plus detection of outliers, fading ads and underfunded winners.
  • Concept clustering from tags and script embeddings, with a spend-weighted diversity score.
  • Claude agents with read-only tools that write the strategist report and creative briefs. A validator checks every cited number against the database before a report is saved.
  • A Meta Marketing API sync with pagination, throttling backoff, idempotent upserts and scheduled re-pulls.

how it works

Ads and creatives sync from the Meta Marketing API. Media is stored privately and split into scenes with PySceneDetect. Gemini tags each ad, and Gemini embeddings group similar scripts. The analytics layer computes shrunk KPIs per tag across 7-day, 30-day, 90-day and all-time windows, and Claude agents write the report from those results.

evaluation

  • A synthetic data generator plants known patterns, such as a winning hook, fading ads, a hidden winner and near-duplicates, and checks that the analysis finds them. It runs in CI and nightly, and has passed all 7 checks on every run since October 24.
  • Grounding: all 131 cited numbers across 4 reports matched the database.
  • 133 Python tests.

status

In active development, with a demo-ready MVP planned for December 2026. The web app, the worker and a public read-only demo are live. Meta App Review and onboarding are next.

stack

React, Vite, TypeScript and Tailwind on Vercel. Supabase (Postgres, pgvector, Storage, Vault). Python and FastAPI on Modal. Gemini for tagging and embeddings, Claude for agents, Langfuse for tracing, GitHub Actions for CI.
