Appalachian Adventure Co.

client · 2026

A rebuild of a North Carolina real estate firm’s website in Framer, with a listing system the broker can run himself and compliance built in.

the ask

The old Wix site still read as an adventure-guiding business, with real estate buried, and it lacked the firm disclosure the law requires. The broker wanted to post a listing from his phone in a couple of minutes, with nothing on the site creating regulatory risk.

what i built

  • A listing system in the Framer CMS. Each listing pulls its agent from the team record, so agent cards and team pages fill in automatically, and sold listings keep their page.
  • Compliance built into the system: a disclosure footer on every page, acreage shown as “+/- acres”, listings that start as drafts, and forms that never ask about finances.
  • A full migration from an extracted copy of the old site, with all seven blog posts at their original URLs and 33 old URLs mapped for redirects.
  • Responsive layouts for desktop, tablet and phone, built from reusable components.
  • A plain-language operator guide so the broker can run the site himself.

status

Built and revised in October 2026. Launch is waiting on the client’s Framer plan upgrade and final approval.

stack

Framer and Framer CMS, edited through Framer’s command-line agent tool from Claude Code. Python and HTTrack to extract the old site.
