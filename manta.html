Manta

web · 2026

A live analytics terminal for prediction markets. It records Kalshi and Polymarket around the clock and turns the data into a screener of 5,000+ contracts, live order books, a side-by-side view of both venues and independent fair values.

problem

Traders on Kalshi and Polymarket have no single place to find contracts, see how much can actually be traded, compare the same event on both venues or check whether a price is fair. Kalshi doesn’t publish past order books, so its liquidity can’t be studied unless someone records it.

what i built

  • A screener for every open crypto, economics and financial contract on both venues, filtered by venue, expiry, spread, volume, depth and distance from fair value.
  • Contract pages with the live order book, a price chart, the payoff in plain English and what buying or selling a given size costs after slippage and fees.
  • Fair values labelled by method: Bitcoin and Ether priced from Deribit’s options market, everything else from one curve fitted to both venues’ order books.
  • A cross-venue view of the same event on both venues that flags price gaps still worth taking after fees.
  • Minute-by-minute replay of past Kalshi order books, rebuilt from the recordings.
  • An accuracy page that scores market prices and Manta’s fair values against settled outcomes, plus watchlists and email alerts.

how it works

A recorder written in Go streams order books and trades from six venues (Kalshi, Polymarket, Deribit, Coinbase, Kraken and Binance) into hourly files on a small server, written so a crash loses at most a second. Every minute, Python jobs list contracts, compute fair values and check alerts, and write the results to Postgres. The Next.js site reads straight from that database. All the pricing math is written by hand.

by the numbers

  • 2.38 billion messages recorded from six venues in ten days, with over 99% coverage on each
  • Over one rebuilt hour of 26.4 million updates, the order book matched Kalshi’s own snapshots in all 16,630 checks
  • On 206 settled Bitcoin contracts, the fair value was as accurate as Kalshi’s own price an hour before close (Brier score 0.112 vs 0.114)
  • 5,069 contracts in the screener, 3,640 with a fair value

stack

Go, Python and TypeScript. Next.js and React on Vercel. Postgres on Supabase. A Hetzner server running systemd services. NautilusTrader for backtest data.
